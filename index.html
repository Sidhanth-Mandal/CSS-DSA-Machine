The CSS Machine

This page runs Euclid's greatest-common-divisor algorithm and LeetCode 704's binary search using nothing but HTML and CSS. HTML is the memory. CSS is the processor. You are the clock.

A while loop

The simplest loop that does something: count n down to zero. CSS computes n - 1 and decides whether the loop may continue. The green button is the loop body. When the condition goes false, the button stops existing.

#w-7:checked ~ .machine { --n: 7; }      /* ...one rule per value */

/* condition: 1 while n > 0, then 0 */
.m-while { --run: clamp(0, var(--n), 1); }

/* body: put the label that writes (n - 1) inside the window */
.m-while .strip { translate: 0 calc((var(--n) - 1) * var(--h) * -1); }

/* the loop guard: no condition, no button */
.step { scale: var(--run); }
02

An if / else statement

CSS has no > operator, so we build one. clamp(0, x - y, 1) is 1 when x > y and 0 otherwise. That single bit picks the branch: it lights up the taken path, hides the other, and selects the result with gt * x + (1 - gt) * y. Pick two numbers and watch the branch flip.

Show the CSS that makes the decision 
/* comparator: 1 when x > y, 0 otherwise (integers only) */
.m-if { --gt: clamp(0, var(--x) - var(--y), 1); }

/* branchless select: a 2-way multiplexer */
.m-if { --max: calc(var(--gt) * var(--x) + (1 - var(--gt)) * var(--y)); }

/* gates: an element exists only on its branch */
.when-gt { scale: var(--gt); }
.when-le { scale: calc(1 - var(--gt)); }

Euclid's GCD, ~300 BC, running in a stylesheet

Now we nest the if/else inside the while loop. The loop runs while a ≠ b. Each tick subtracts the smaller number from the larger one. When they meet, that number is the greatest common divisor. Pick any a and b from 1 to 30, then press the button until it disappears.

Show the CSS that runs Euclid 
.m-gcd {
  --gt:  clamp(0, var(--a) - var(--b), 1);   /* a > b            */
  --lt:  clamp(0, var(--b) - var(--a), 1);   /* a < b            */
  --run: calc(var(--gt) + var(--lt));        /* a != b  (while)  */
}

/* loop guard */
.step { scale: var(--run); }

/* if (a > b) a = a - b; */
.m-gcd .strip-a {
  scale: var(--gt);
  translate: 0 calc((var(--a) - var(--b) - 1) * var(--h) * -1);
}

/* else b = b - a; */
.m-gcd .strip-b {
  scale: var(--lt);
  translate: 0 calc((var(--b) - var(--a) - 1) * var(--h) * -1);
}

LeetCode 704 · Binary Search, solved by a stylesheet

A sorted array, a target, and a processor that halves the search space every time you press the button. HTML holds lo and hi. CSS computes mid, reads nums[mid], compares, and picks the branch.

Easy704. Binary Search

Given an array of integers nums sorted in ascending order and an integer target, return the index of target in nums, or -1 if it is not there.

You must write an algorithm with O(log n) runtime complexity.

Here n = 10, so the machine needs at most ⌊log₂ 10⌋ + 1 = 4 clicks for any target.

Pick a dataset and a target, then press the step button until it disappears. Grey cells have been ruled out. Try a target that is not in the array, such as 24, and watch lo cross hi.

  --active: clamp(0, var(--hi) - var(--lo) + 1, 1);                   /* 1 while lo <= hi  */

}
.step { scale: var(--run); }   /* no work left, no button */
nums[mid]: indexing an array without indexing 
/* CSS can't do nums[mid], so every slot votes: k_i = 1 only when mid == i */
--k3: max(0, 1 - max(var(--mid) - 3, 3 - var(--mid)));     /* max(0, 1 - |mid - 3|) */
--m:  calc(var(--k0) * var(--v0) + var(--k1) * var(--v1) + ... + var(--k9) * var(--v9));
if / else if / else: a three-way comparison 
--lt: clamp(0, var(--t) - var(--m), 1);     /* nums[mid] < target  */
--gt: clamp(0, var(--m) - var(--t), 1);     /* nums[mid] > target  */
--eq: calc(1 - var(--lt) - var(--gt));      /* nums[mid] == target */

--found: calc(var(--active) * var(--eq));   /* if      → return mid */
--right: calc(var(--active) * var(--lt));   /* else if → lo = mid+1 */
--left:  calc(var(--active) * var(--gt));   /* else    → hi = mid-1 */
lo = mid + 1 and hi = mid − 1: the write-back 
.strip-lo { scale: var(--right); translate: 0 calc((var(--mid) + 1) * var(--h) * -1); }
.strip-hi { scale: var(--left);  translate: 0 calc(var(--mid) * var(--h) * -1); }
